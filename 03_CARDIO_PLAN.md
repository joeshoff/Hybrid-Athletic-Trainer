# Hybrid Cardio Plan

## Purpose

Cardio exists to build:

- aerobic capacity
- VO2 capacity
- endurance
- athletic conditioning
- work capacity
- outdoor capability

while preserving strength, muscle and recovery.

The goal is not to become primarily a runner.

## Baseline Weekly Architecture

### Monday

Zone 2 / aerobic base

Target: 40–50 minutes

Generally conversational effort.

Rotate modality as appropriate:

- treadmill
- bike
- elliptical
- outdoor walk/jog

### Tuesday

VO2 / quality

Target: 30–45 minutes total

This is the week's genuinely hard aerobic stimulus.

Possible modalities:

- treadmill
- bike
- elliptical
- boxing/conditioning when appropriate

Do not repeatedly use steep treadmill inclines.

A previous slight glute pull makes aggressive incline work something to dose carefully.

### Wednesday

OFF

No planned cardio.

### Thursday

Aerobic / mixed

Target: 40–60 minutes

Preferably use a different modality from Monday.

This may be:

- Zone 2
- aerobic intervals
- mixed aerobic work
- moderate endurance session

Keep intensity appropriate to Thursday's Upper B strength session and the Friday/Saturday workload.

### Friday

Boxing

Target: 30–45 minutes

Generally approximately one boxing session per week.

Boxing does not automatically need to be maximal HIIT.

Emphasize skill, movement, conditioning and appropriate intensity.

### Saturday

Long outdoor / adventure

Target: 45–90+ minutes.

Possible:

- hiking
- rucking
- outdoor running
- cycling
- mixed adventure session

A 60-lb weight vest is high-load conditioning.

With the vest:

- prefer hiking/walking/controlled incline
- avoid routinely running with it
- do not increase load and duration simultaneously

### Sunday

OFF

No planned cardio.

## Cardio Distribution

Typical target:

- 2–3 easy aerobic sessions
- 1 VO2-quality session
- 1 boxing/skill-conditioning session
- 1 flexible Saturday adventure session

Avoid making every session medium-hard.

## Core Work

Direct core training is a deliberate addition alongside cardio — the strength program's existing trunk work (Pallof press, farmer's walks, cable stand-up) is anti-rotation/loaded-carry work only. It does not cover anti-extension or general core conditioning, so it doesn't substitute for a dedicated core block.

Standard: 2x/week, 10–15 minutes, attached to the two easy aerobic cardio days (Monday, Thursday) — done *after* the cardio session, not before. Doing core work first pre-fatigues trunk stability needed for cardio posture/breathing and can spike heart rate in a way that muddies Zone 2 pacing.

Do not attach core work to Tuesday (VO2) or Friday (boxing) — the week's two genuinely hard days — or to Saturday's open-ended long session; adding volume there competes with quality or recovery. Do not add it to Wednesday/Sunday off days — those stay fully off per the recovery-priority hierarchy rather than quietly becoming training days.

Emphasize anti-extension and anti-rotation patterns (planks, dead bugs, bird dogs, rotational work) over spinal-flexion-heavy work (crunches/sit-ups). This pattern preference is a coaching inference for a 60-year-old athlete with the program's existing knee/ankle considerations, not a documented research finding.

Apple Fitness's core workout library is an acceptable session source — select for the pattern emphasis above rather than defaulting to whatever is queued next.

When overall weekly load needs to come down, core work trims at the same priority as optional/high-impact conditioning — before the four core strength sessions and the week's VO2 stimulus, per the existing trim order.

## Cardio Coaching Workflow (Adaptive Decision Procedure)

This is the durable framework, not a fixed list of six permanent workouts. The baseline architecture above sets the *type* of session for each day. The actual session — duration, intensity, modality — gets decided fresh each time using this procedure. This section is what makes the loop repeatable; the current week's actual outputs live in 04_TODAY.md, not here.

**Inputs, checked in this order:**

1. **Day's position in the weekly architecture** — which slot (Zone 2 / VO2 / mixed aerobic / boxing / long outdoor / off) is the baseline default for today.
2. **Actual training from the prior 1–3 days** — the log, not the plan: what was actually done, at what load/intensity, whether it was on-program or off-program, and how it landed.
3. **What's coming in the next 1–2 days** — a heavy Lower B or long Saturday effort ahead pulls intensity down today; a rest day ahead opens room to push.
4. **Current fatigue/recovery** — sleep, reported energy, subjective readiness.
5. **Strength performance signal** — did the most recent strength session hit prescribed loads/reps at the intended RPE, or did it grind.
6. **Joint status** — knee and right-ankle soreness or flare, checked explicitly every time, never assumed clean.
7. **Recent cardio load** — how hard and how much cardio landed in the last 3–4 days, independent of today's slot.
8. **Modality rotation** — which modalities were used recently, so the same tool isn't repeated two days running without a reason.

**Output rules:**

- The weekly slot sets the session *type*. It is never skipped outright without a stated reason.
- Duration and intensity move within that type based on inputs 2–7 — a VO2 day stays a VO2 day, but it might land at 30 minutes/RPE 8 instead of 45 minutes/RPE 9.
- Modality is chosen to protect joints first (bike/elliptical over treadmill incline when knee or ankle is flagged), rotation second.
- Hard lower-body strength the day before pulls the next day's cardio prescription down a notch by default — it doesn't automatically cancel it.
- No more than one genuinely hard cardio day per week (the VO2 slot). The other 4–5 cardio touches stay easy-to-moderate even when recovery is good — good recovery raises quality within a slot, it does not create a second hard slot.
- When the week's overall load needs to come down, the trim order is: Saturday wildcard first, then optional/high-impact conditioning, then cardio duration/intensity — the four core strength sessions and the week's single VO2 stimulus are protected last.
- Every prescription states which inputs drove it. A modification is a visible, explained decision, not a silent drift from baseline.

## Adaptive Rules

The coach should adjust cardio based on:

- previous day's strength
- leg soreness
- joint status
- sleep/recovery when available
- recent cardio load
- heart rate
- RPE
- performance
- upcoming strength demands

If Tuesday Lower A causes substantial leg fatigue, Thursday cardio should not automatically remain aggressive.

If recovery is poor:

1. reduce Saturday wild-card work
2. reduce optional/high-impact conditioning
3. reduce cardio intensity or duration as appropriate
4. protect the core strength architecture and weekly VO2 stimulus where possible

## Running

Do not assume treadmill speed equals outdoor effort.

Use:

- speed
- incline
- heart-rate zone
- RPE
- terrain

to determine actual effort.

When comparing treadmill and outdoor running, distinguish research-supported conclusions from coaching estimates.

The coach runs the Cardio Coaching Workflow above to create the actual cardio prescription for the current day/week. This file defines how that decision gets made — it does not dictate exact workouts. The current week's actual prescriptions live in 04_TODAY.md as a short-term artifact, separate from this framework.
